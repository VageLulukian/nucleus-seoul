# NUCLEUS — экран «Сеул» (reel-02, реквизит)

Веб-реквизит для съёмки: вертикальный (9:16) экран Nucleus. Открыть на телефоне →
«Добавить на экран Домой» → запускается как полноэкранное приложение; после первой
загрузки работает офлайн (service worker). Открыть: **seoul.html**
(чистый кадр: `seoul.html?fit=shoot`). Исходник/доки — в приватном основном репо.
